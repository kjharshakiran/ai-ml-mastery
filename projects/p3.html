🏆 Capstone Project 3

Image Classifier with CNNs & Transfer Learning

🟡 Difficulty: Intermediate🎯 Teaching a machine to see🧰 PyTorch · Conv/Pool · Training loops · ResNet

What you'll build

  • A convolutional neural network from scratch in PyTorch that classifies FashionMNIST images.
  • A clean, reusable training loop: dataloaders → forward → loss → backward → step.
  • An honest evaluation on a held-out test set (accuracy + per-batch loss curve).
  • A transfer-learning version: fine-tune a pretrained ResNet-18 and compare.
  • The intuition for why a model trained on millions of unrelated photos jump-starts your tiny task.
The Big Question
An image is just a grid of pixel numbers. How does a network learn to ignore where an object sits, what lighting it's under, and which exact pixels fired — and still say "that's a sneaker"?

A 28×28 grayscale image is a vector of 784 numbers; a colour photo is far bigger. Feeding that to a plain MLP wastes everything we know about images: that a pattern (an edge, a corner) means the same thing wherever it appears. The convolution (Week 28) bakes that knowledge in — it slides a small learnable filter across the image, detecting a feature everywhere at once.

🧒 Explain Like I'm 10

Picture a tiny stamp with a pattern on it — say, a short diagonal line. You press that stamp all over a picture and mark every spot where the picture matches the stamp. Now you have a map of "where are the diagonal lines?" A CNN has hundreds of these stamps, and it learns what each stamp should look like. Early stamps find edges; later ones combine edges into shapes; the last ones recognise whole objects like "shoe" or "shirt".

The CNN architecture we'll build

Step 1 — Dataloaders

FashionMNIST ships with torchvision: 60k training + 10k test grayscale clothing images in 10 classes. A DataLoader batches and shuffles them so we never load all of memory at once.

step1_data.py
import torch
from torch.utils.data import DataLoader
from torchvision import datasets, transforms

device = "cuda" if torch.cuda.is_available() else "cpu"

# Normalise pixels to roughly mean 0, std 1 -> faster, stabler training.
tfm = transforms.Compose([
    transforms.ToTensor(),                  # [0,255] uint8 -> [0,1] float tensor
    transforms.Normalize((0.286,), (0.353,)) # FashionMNIST channel stats
])

train_ds = datasets.FashionMNIST(".", train=True,  download=True, transform=tfm)
test_ds  = datasets.FashionMNIST(".", train=False, download=True, transform=tfm)

train_dl = DataLoader(train_ds, batch_size=128, shuffle=True)
test_dl  = DataLoader(test_ds,  batch_size=256)

images, labels = next(iter(train_dl))
print(images.shape)   # -> torch.Size([128, 1, 28, 28])  (batch, channels, H, W)

Step 2 — Define the CNN

Two convolution+pool stages, then a classifier head. Each Conv2d learns a stack of filters; MaxPool2d halves the spatial size, building the position-invariance the analogy promised.

step2_model.py
import torch.nn as nn

class SmallCNN(nn.Module):
    def __init__(self, n_classes=10):
        super().__init__()
        self.features = nn.Sequential(
            nn.Conv2d(1, 32, kernel_size=3, padding=1),  # 1->32 feature maps
            nn.ReLU(),
            nn.MaxPool2d(2),                             # 28x28 -> 14x14
            nn.Conv2d(32, 64, kernel_size=3, padding=1), # 32->64 maps
            nn.ReLU(),
            nn.MaxPool2d(2),                             # 14x14 -> 7x7
        )
        self.classifier = nn.Sequential(
            nn.Flatten(),               # 64 x 7 x 7 -> vector of 3136
            nn.Linear(64 * 7 * 7, 128),
            nn.ReLU(),
            nn.Dropout(0.3),            # regularisation (Week 27)
            nn.Linear(128, n_classes),  # 10 raw class scores (logits)
        )

    def forward(self, x):
        return self.classifier(self.features(x))

model = SmallCNN().to(device)
print(sum(p.numel() for p in model.parameters()), "trainable parameters")

Step 3 — The training loop

This loop is the beating heart of all deep learning (Weeks 25–26). Memorise its five lines: zero the gradients, forward pass, compute loss, backpropagate, step the optimiser.

step3_train.py
loss_fn = nn.CrossEntropyLoss()                 # softmax + NLL for classification
opt = torch.optim.Adam(model.parameters(), lr=1e-3)

def train_one_epoch(model, dl):
    model.train()
    running = 0.0
    for images, labels in dl:
        images, labels = images.to(device), labels.to(device)
        opt.zero_grad()                 # 1. clear old gradients
        logits = model(images)          # 2. forward pass
        loss = loss_fn(logits, labels)  # 3. how wrong are we?
        loss.backward()                 # 4. backprop -> gradients
        opt.step()                      # 5. Adam updates the weights
        running += loss.item() * images.size(0)
    return running / len(dl.dataset)

for epoch in range(1, 6):               # 5 epochs is plenty for FashionMNIST
    avg_loss = train_one_epoch(model, train_dl)
    print(f"epoch {epoch}  train loss {avg_loss:.4f}")

Step 4 — Evaluate

Switch to eval mode (turns off dropout), disable gradient tracking for speed, and count correct predictions on the test set the model never trained on.

step4_evaluate.py
@torch.no_grad()
def accuracy(model, dl):
    model.eval()
    correct = total = 0
    for images, labels in dl:
        images, labels = images.to(device), labels.to(device)
        preds = model(images).argmax(dim=1)   # pick highest-scoring class
        correct += (preds == labels).sum().item()
        total   += labels.size(0)
    return correct / total

print(f"Scratch CNN test accuracy: {accuracy(model, test_dl):.3f}")
# A 5-epoch SmallCNN typically lands around 0.90 on FashionMNIST.
🎓 Real-World Analogy for transfer learning

Hiring a fresh graduate (random weights) means months of training. Hiring someone who already spent years recognising millions of images (a pretrained ResNet) means they already know edges, textures, fur, wheels — you just teach them your specific job. Transfer learning is reusing that hard-won general vision and only retraining the final "what is this for my task" layer.

Step 5 — Transfer learning with ResNet-18

Now the modern shortcut (Week 29). We load a ResNet-18 pretrained on ImageNet, freeze its convolutional backbone, and replace only its final layer with a fresh 10-class head. We adapt FashionMNIST (1 channel, 28px) to what ResNet expects (3 channels, 224px) in the transform.

step5_transfer.py
from torchvision import models

# ResNet expects 3x224x224 RGB; adapt grayscale FashionMNIST to match.
tfm_rn = transforms.Compose([
    transforms.Resize(224),
    transforms.Grayscale(num_output_channels=3),   # 1 -> 3 channels
    transforms.ToTensor(),
    transforms.Normalize([0.485,0.456,0.406], [0.229,0.224,0.225]),  # ImageNet stats
])
rn_test = DataLoader(datasets.FashionMNIST(".", train=False, transform=tfm_rn),
                     batch_size=128)

resnet = models.resnet18(weights=models.ResNet18_Weights.DEFAULT)
for p in resnet.parameters():
    p.requires_grad = False                 # FREEZE the pretrained backbone

# Swap the 1000-class ImageNet head for our 10-class head (these weights DO train).
resnet.fc = nn.Linear(resnet.fc.in_features, 10)
resnet = resnet.to(device)

# Only the new head's parameters are optimised -> fast, data-efficient.
opt_rn = torch.optim.Adam(resnet.fc.parameters(), lr=1e-3)
# Train resnet with the SAME train_one_epoch loop (on a 224px train loader),
# then call accuracy(resnet, rn_test).
#
# Even after just 1-2 epochs of training ONLY the head, the pretrained
# features push accuracy to ~0.92+ -- matching or beating the scratch CNN
# with a fraction of the trained parameters. That is the power of transfer.
🔑 Why transfer learning wins

The early layers of any vision network learn nearly identical things — edges, blobs, textures — regardless of the final task. Those layers are expensive to learn but universal, so we reuse them for free. You only pay to train the last layer that's specific to your classes. This is how teams ship strong image models with hundreds of examples instead of millions.
