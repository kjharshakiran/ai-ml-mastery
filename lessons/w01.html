The Big Picture: What is AI, really?

⏱️ 20 min🎯 Intuition only — no math yet📦 Week 1

By the end of this lesson you'll be able to…

  • Explain what "machine learning" means to a friend in one sentence.
  • Describe the single mental model that connects all 40 weeks of this course.
  • Tell the difference between AI, Machine Learning, and Deep Learning.
  • See the path from "data is a list of numbers" to "ChatGPT writes a poem."
The Big Question
How can a machine — which only knows numbers — learn to recognise a cat, predict a price, or write a sentence it has never seen before?

1. Programming vs. Machine Learning

For 70 years, we told computers exactly what to do, step by step. Want to add up a shopping bill? You write the rule: "add each price." That's traditional programming: rules in → answers out.

But how do you write the rule for "is this photo a cat?" Try it. "It has pointy ears" — so do foxes. "It has whiskers" — so do walruses. Every rule you write has a thousand exceptions. Cats are easy to recognise but impossible to describe. This is the wall that classical programming hit.

Machine learning flips the whole thing around. Instead of writing the rule, you show the computer thousands of examples ("this is a cat 🐱, this is not 🐶") and let it figure out the rule by itself. That's the entire revolution in one sentence:

🔑 The core flip

Traditional programming: Rules + Data → Answers.
Machine learning: Data + Answers → Rules. We give the machine examples, and it learns the rule that fits them.

🧒 Explain Like I'm 10

Imagine teaching a little kid what a dog is. You don't hand them a 50-page rulebook on ears and tails. You point at dogs: "dog!… dog!… that's a dog too!" After enough pointing, the kid just knows — even for breeds they've never seen. Machine learning is pointing at examples until the computer "just knows." The pointing is called training.

2. The secret that makes it all work: everything becomes numbers

Here's the trick at the heart of this entire course. A computer can't see a cat or read a word. It only does arithmetic. So before anything else, we turn every kind of thing into a list of numbers — a vector.

  • A photo? A grid of brightness numbers (one per pixel).
  • A word? A list of numbers that captures its meaning (you'll build these in Week 31!).
  • A customer? [age, income, num_purchases, …].
  • A sound? The air-pressure value measured 44,100 times a second.

Once everything is a vector, every problem becomes geometry: similar things are close together in number-space, different things are far apart. "Learning" becomes "find a way to move and slice this space of points so the useful patterns line up."

3. AI vs. Machine Learning vs. Deep Learning

These three words get mixed up constantly. They're actually nested, like Russian dolls:

TermWhat it meansExample
Artificial IntelligenceThe big goal: machines doing things that seem "smart."A chess engine, a thermostat, Siri.
Machine LearningA way to do AI: learn the rules from data instead of hand-coding them.Spam filters, price prediction.
Deep LearningA kind of ML using many-layered neural networks. Great for images, audio, language.ChatGPT, face unlock, self-driving vision.

AI ⊃ Machine Learning ⊃ Deep Learning. This course walks you straight through all three, in order.

4. The map of this journey

Here's why the weeks are ordered the way they are — each one is a tool you'll need for the next:

  • Parts 1–2 (Weeks 2–8) — Foundations. The math (vectors, change, chance) and the tools (Python, SQL, data analysis). This is your toolbox.
  • Part 4 (Weeks 11–23) — Classical ML. Your first real learning machines: regression, classifiers, clustering. Simple, powerful, still used everywhere.
  • Part 5 (Weeks 24–31) — Deep Learning. Neural networks: stack simple pieces into something that learns images and sequences.
  • Part 6 (Weeks 32–37) — Transformers & Generative AI. The architecture behind ChatGPT and image generators.
  • Part 7 (Weeks 38–40) — Production. Getting models out into the real world.

✅ Check Yourself

In one line: what is the key difference between traditional programming and machine learning?
Exactly. We hand the machine examples (data + the right answers) and it discovers the rule — instead of us writing the rule by hand. Everything else in this course is detail on how it discovers that rule.
Why do we turn images, words, and sounds into vectors (lists of numbers)?
Numbers are the only thing a computer can compute with. Representing everything as vectors turns every AI problem into geometry — and geometry is something math can chew on.
