The Big Question
A dataset has 784 features (the pixels of a digit). Can we throw away 99% of them and still see the structure — even plot it on a flat page?

1. Dimensionality reduction: fewer axes, same story

Last week we scaled features so they'd compete fairly. This week we go further: we combine them. Most high-dimensional data is secretly low-dimensional — its features are correlated, so the "true" information lives on a thin slab inside the big space. Dimensionality reduction finds that slab and re-describes the data using just a handful of new axes.

Two famous techniques do this with linear algebra: PCA (unsupervised — ignores labels, keeps variance) and Fisher LDA (supervised — uses labels, keeps class separation). Both project data onto a few well-chosen directions; they just disagree about what "well-chosen" means.

🧒 Explain Like I'm 10

Think of a fish. It's a 3D object, but if someone asks "what does it look like?" you draw its side view, not the head-on view — because the side shows the most. PCA is a machine that automatically finds the "side view" of your data: the flat picture that keeps the most of what makes the data interesting.

2. The PCA procedure, step by step

PCA looks for the directions along which the data varies the most. Spread = information; a direction where all points have the same value tells you nothing. Here's the recipe.

Step 1 — Centre the data. Subtract the mean of each feature so the cloud is centred at the origin: \(\tilde{\mathbf{x}}_i = \mathbf{x}_i - \boldsymbol{\mu}\). (We also scale first, per Week 19, so no feature fakes large variance with big units.)

Step 2 — Build the covariance matrix. Covariance measures how features vary together. For centred data \(\tilde{X}\) (rows = points), the \(d \times d\) covariance matrix is:

\[ C = \frac{1}{n-1}\,\tilde{X}^{\top}\tilde{X}, \qquad C_{jk} = \frac{1}{n-1}\sum_{i=1}^{n} \tilde{x}_{ij}\,\tilde{x}_{ik} \]

The diagonal holds each feature's variance; the off-diagonals say how pairs of features move together. A big positive \(C_{jk}\) means features \(j\) and \(k\) rise and fall in sync.

Step 3 — Take its eigenvectors. Here's where Week 2 returns in force. The eigenvectors of the covariance matrix are the principal axes, and each eigenvalue tells you how much variance lies along its axis:

\[ C\,\mathbf{v} = \lambda\,\mathbf{v} \]

The eigenvector with the largest eigenvalue \(\lambda_1\) points along the direction of greatest spread — that's Principal Component 1. The next-largest, orthogonal to it, is PC2, and so on. Because \(C\) is symmetric, its eigenvectors are guaranteed orthogonal — a perfectly clean new coordinate system.

Step 4 — Keep the top \(k\). Sort eigenvectors by eigenvalue, keep the top \(k\), and project the data onto them. You've gone from \(d\) dimensions to \(k\) while throwing away only the low-variance "noise" directions.

🔑 The one thing to remember

PCA = eigen-analysis of the covariance matrix. The eigenvectors are the new axes (principal components); the eigenvalues are how much variance each one carries. Keep the high-eigenvalue axes, discard the rest. (Equivalently, run SVD on the centred data — same answer, more numerically stable. That's the Week 2 SVD in action.)

3. Reading the variance: how many axes do I keep?

Each eigenvalue \(\lambda_i\) is the variance along PC\(i\). The fraction of total information captured by PC\(i\) is its explained variance ratio:

\[ \text{ratio}_i = \frac{\lambda_i}{\sum_{j=1}^{d}\lambda_j} \]

Stack these up and you get a cumulative curve. A common rule: keep enough components to retain, say, 95% of the variance. Often a 784-dimensional image dataset needs only ~50 components for 95% — a 15× compression with almost no loss.

🎒 Real-World Analogy

Packing for a trip with a tiny suitcase. You can't bring all 784 items, so you rank them by usefulness and pack the top few. The explained-variance ratio is your "usefulness score" per item; the cumulative curve tells you when the suitcase is "good enough" (95% packed) and you can stop.

scikit-learn — PCA on the digits dataset
import numpy as np
from sklearn.datasets import load_digits
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA

X, y = load_digits(return_X_y=True)     # 1797 samples, 64 pixel features
X = StandardScaler().fit_transform(X)   # Week 19: scale BEFORE PCA

# Project 64-D pixels down to 2-D for plotting
pca = PCA(n_components=2)
X2 = pca.fit_transform(X)               # centre + covariance + eigenvectors, done for you
print("shape after PCA:", X2.shape)               # -> (1797, 2)
print("variance kept by PC1, PC2:",
      pca.explained_variance_ratio_.round(3))     # e.g. [0.12 0.10]

# How many components to keep 95% of the variance?
full = PCA().fit(X)
cum = np.cumsum(full.explained_variance_ratio_)
k95 = np.searchsorted(cum, 0.95) + 1
print(f"{k95} components keep 95% of the variance (out of 64)")

4. PCA in action — and what it can't do

Projecting those 64-pixel digits to 2D, the digits cluster into rough blobs you can see — that's PCA's superpower: turning unplottable data into a picture. It also de-noises (the discarded directions are mostly noise) and speeds up downstream models by shrinking the input.

But PCA is blind to labels. It chases variance, not usefulness for prediction. Sometimes the direction of greatest spread is irrelevant to the class you care about, and the direction that actually separates the classes has small variance — so PCA happily discards it. That's the gap Fisher LDA fills.

5. Fisher Linear Discriminant Analysis: separate, don't just spread

LDA is supervised. Instead of "find the direction of maximum variance," it asks: "find the direction that best separates the classes." Project the data onto a line so that, after projecting, the class means are far apart and each class stays tightly clustered. Fisher captured this as a single ratio to maximise:

\[ J(\mathbf{w}) = \frac{\mathbf{w}^{\top} S_B\, \mathbf{w}}{\mathbf{w}^{\top} S_W\, \mathbf{w}} = \frac{\text{between-class scatter}}{\text{within-class scatter}} \]

where \(S_B\) measures how far apart the class means are and \(S_W\) measures the spread inside each class. Maximise the gap between classes; minimise the smear within them. The optimal direction works out to \(\mathbf{w} \propto S_W^{-1}(\boldsymbol{\mu}_1 - \boldsymbol{\mu}_2)\) for two classes.

6. Classifying on the reduced representation & multiclass

Once LDA has projected the data onto its discriminant direction(s), classification is easy: a new point is assigned to the class whose projected mean it lands nearest (with the threshold sitting between the projected class means). For \(c\) classes, LDA can find up to \(c-1\) discriminant directions — so 10 digit classes give up to 9 LDA axes, a compact and class-aware representation. Each axis is chosen to maximise that same between/within scatter ratio, generalised to many classes.

In short: PCA compresses for visualisation and de-noising; LDA compresses and sharpens class boundaries, doubling as a lightweight classifier. They're often complementary — PCA first to denoise, LDA after to separate.

scikit-learn — LDA as a classifier
from sklearn.datasets import load_digits
from sklearn.preprocessing import StandardScaler
from sklearn.discriminant_analysis import LinearDiscriminantAnalysis as LDA
from sklearn.model_selection import train_test_split

X, y = load_digits(return_X_y=True)
X = StandardScaler().fit_transform(X)
Xtr, Xte, ytr, yte = train_test_split(X, y, test_size=0.3, random_state=0)

lda = LDA()                 # supervised: uses the labels y
lda.fit(Xtr, ytr)
print("LDA test accuracy:", round(lda.score(Xte, yte), 3))   # ~0.95

# LDA can also project to (#classes - 1) = 9 dims for a compact representation
X_proj = lda.transform(Xtr)
print("LDA projection shape:", X_proj.shape)   # -> (n_train, 9)

✅ Check Yourself

In PCA, what do the eigenvectors of the covariance matrix represent?
PCA is eigen-analysis of the covariance matrix. Each eigenvector is a principal component (a new axis), and its eigenvalue is the variance carried along that axis — exactly the Week 2 idea applied to data.
What is the key difference between PCA and Fisher LDA?
PCA ignores labels and chases maximum variance. LDA uses labels and chases the direction that best separates the classes (maximising between-class over within-class scatter).
You run PCA and the first 3 components have explained_variance_ratio_ = [0.6, 0.25, 0.1]. How much variance do the first two components retain?
The explained-variance ratios add up: 0.60 + 0.25 = 0.85, so keeping PC1 and PC2 retains 85% of the total variance — usually plenty for a 2D plot.
