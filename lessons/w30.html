RNNs I: Sequences, LSTM & GRU

  • Write the recurrence \(h_t = f(W h_{t-1} + U x_t)\) and explain the hidden state as memory.
  • Name the RNN shapes: one-to-many, many-to-one, many-to-many.

The Big Question
A CNN sees a whole image at once. But the meaning of "I love this — not!" depends entirely on a word that arrives at the end. How do we build a network that reads things in order, remembers what it has seen, and lets earlier words change how it understands later ones?

30.1 Sequential patterns: when order is the meaning

So far every model treated each input independently and as a fixed-size block — a row of features, an image of set dimensions. But enormous swathes of the world are sequences, where order carries the meaning and the length varies: a sentence, a song, a stock price over time, a patient's vital signs, the frames of a video. "Dog bites man" and "man bites dog" use the same words; only the order separates a non-event from headline news. To handle these we need a model that processes inputs one step at a time and carries information forward.

30.2 Machine learning for sequences

You could try to bolt sequences onto the tools you know, but each cracks. A dense network (Week 24) needs a fixed-size input — but sentences vary in length. A CNN (Week 28) handles local windows nicely with its 1D convolution, but its receptive field is limited; capturing "not" at the end flipping "love" at the start requires reaching across the whole sequence. What we really want is a network with a memory that updates as it reads, so context from step 1 can still influence step 50. That is precisely the Recurrent Neural Network (RNN).

🧒 Explain Like I'm 10

When you read a story, you don't forget the first sentence by the time you reach the last — you keep a little summary in your head and update it with each new word. An RNN does the same: it reads one word, jots a quick note to itself, reads the next word plus its note, updates the note, and on it goes. That running note is its memory.

30.3 The recurrence: one cell, reused every step

An RNN has a hidden state \(h_t\) — a vector that is its memory. At each time step it takes the current input \(x_t\) and the previous memory \(h_{t-1}\), mixes them, and produces a new memory \(h_t\):

\[ h_t \;=\; f\!\left(W\,h_{t-1} \;+\; U\,x_t \;+\; b\right) \]

Here \(U\) weights the new input, \(W\) weights the carried-over memory, \(b\) is a bias, and \(f\) is a nonlinearity (classically \(\tanh\)). The output at each step is read off the state, e.g. \(y_t = V h_t\). The crucial point — just like weight sharing in a CNN — is that the same weights \(W, U, V\) are reused at every time step. This unrolled picture also gives us the RNN shapes, defined by how many inputs map to how many outputs:

  • Many-to-one — read a whole sequence, emit one answer. Sentiment classification (read a review → positive/negative), as drawn above.
  • One-to-many — one input, generate a sequence. Image captioning (one image → a sentence describing it).
  • Many-to-many — sequence in, sequence out. Same length: tag each word with its part of speech. Different length: translation, which we'll meet next week as seq2seq (Week 31).
📓 Real-World Analogy

An RNN is a conveyor belt with one worker. Items (words) glide past one at a time. The worker (the cell) has a single notebook (the hidden state). For each item they glance at their notebook, glance at the item, scribble an updated note, and pass it on. Same worker, same notebook, every step — that's weight sharing across time. The whole story lives in that one running note.

30.4 LSTM & GRU: gates and a memory cell

Plain RNNs have a fatal flaw on long sequences — the same vanishing/exploding gradient problem from Week 25, now in time. Because the same \(W\) is applied at every step, the gradient flowing back through 100 steps is roughly \(W\) multiplied by itself 100 times. If its magnitude is below 1, the signal vanishes and the network forgets the distant past; above 1 and it explodes into instability. A plain RNN simply can't connect "not" at word 100 to "love" at word 1.

The LSTM (Long Short-Term Memory) fixes this with a dedicated memory cell \(c_t\) that flows along an almost-uninterrupted highway — like ResNet's skip connection, but through time. Small neural gates (each a sigmoid producing values in \([0,1]\), acting as soft on/off valves) decide what happens to that memory:

\[ f_t = \sigma(W_f[h_{t-1},x_t]+b_f), \quad i_t = \sigma(W_i[h_{t-1},x_t]+b_i), \quad o_t = \sigma(W_o[h_{t-1},x_t]+b_o) \]

\[ c_t = f_t \odot c_{t-1} \;+\; i_t \odot \tilde{c}_t, \qquad h_t = o_t \odot \tanh(c_t) \]

Read it in plain words: the forget gate \(f_t\) decides what fraction of the old memory \(c_{t-1}\) to keep; the input gate \(i_t\) decides how much of the new candidate \(\tilde{c}_t = \tanh(W_c[h_{t-1},x_t]+b_c)\) to write in; the output gate \(o_t\) decides how much of the memory to expose as this step's hidden state. The symbol \(\odot\) is element-wise multiplication. Because \(c_t\) is updated mostly by addition (keep some old + add some new), gradients flow through it without repeatedly multiplying by \(W\) — so the memory of word 1 can survive to word 100.

The GRU (Gated Recurrent Unit) is a streamlined cousin: it merges the cell and hidden state and uses just two gates (reset and update). Fewer parameters, often just as good, and faster to train. As a rule of thumb: reach for an LSTM or GRU rather than a vanilla RNN whenever sequences are long.

🔑 The one thing to remember

A plain RNN keeps one note and rewrites it from scratch each step, so the distant past fades. An LSTM/GRU adds a protected memory cell with gates — learnable valves that choose what to keep, what to add, and what to reveal. That gated, additive memory is what lets the network remember across long sequences instead of forgetting.

30.5 Backpropagation through time (BPTT)

How does an RNN learn its weights? Exactly the way every network in this part does — gradient descent via backprop (Week 25) — applied to the unrolled network. Since the unrolled RNN is just a very deep feedforward network that happens to reuse the same weights at every layer, we run backprop through all the time steps. This is called Backpropagation Through Time. Each shared weight (\(W\), \(U\), \(V\)) receives a gradient contribution from every step it was used, and we sum them. For very long sequences we often truncate BPTT — only unroll back a fixed number of steps — to keep memory and compute manageable. (And exploding gradients are tamed in practice by gradient clipping: cap the gradient's size before each update.)

numpy — a tiny RNN forward pass over a 3-step sequence
import numpy as np
np.random.seed(0)

# Dimensions: 2-dim inputs, a 3-dim hidden state (memory).
n_in, n_hid = 2, 3

# Shared weights, reused at EVERY time step (this is the key RNN idea).
U = np.random.randn(n_hid, n_in)  * 0.5   # weights new input  x_t
W = np.random.randn(n_hid, n_hid) * 0.5   # weights old memory h_{t-1}
b = np.zeros(n_hid)

# A short sequence: 3 time steps, each a 2-dim vector (e.g. 3 "words").
xs = [np.array([1.0, 0.0]),
      np.array([0.0, 1.0]),
      np.array([1.0, 1.0])]

h = np.zeros(n_hid)               # h_0: memory starts empty
for t, x in enumerate(xs):
    # The recurrence:  h_t = tanh(W h_{t-1} + U x_t + b)
    h = np.tanh(W @ h + U @ x + b)
    print(f"step {t+1}: h = {np.round(h, 3)}")

# h now summarises the WHOLE sequence in one vector. For a many-to-one
# task (e.g. sentiment), read the answer off this final state:
V = np.random.randn(1, n_hid)             # output weights
y = V @ h
print("final summary -> output:", np.round(y, 3))
# Note: only ONE set of {U, W} produced all 3 steps -> weight sharing in time.
🔗 Connect the Dots

RNNs are trained by backprop (Week 25) run across time, and their vanishing-gradient cure echoes the skip connection from Week 29's ResNet. They finally let us model the sequences that NLP (Week 9) is all about. Next lesson, Week 31 (Seq2Seq & Word Embeddings), feeds these cells real word vectors and chains two RNNs for translation. And the long-range memory problem RNNs only partly solve is exactly what attention & transformers (Week 32) will solve outright — replacing recurrence with a mechanism that looks at every step at once.

✅ Check Yourself

In \(h_t = f(W h_{t-1} + U x_t + b)\), what is \(h_{t-1}\)?
\(h_{t-1}\) is the previous memory. Feeding it back in (with shared weight \(W\)) is exactly what makes the network "recurrent" — earlier inputs influence later steps.
Why do LSTMs handle long sequences far better than a vanilla RNN?
The cell state \(c_t = f_t\odot c_{t-1} + i_t\odot\tilde{c}_t\) carries information along an additive highway, and the gates learn what to keep, add and expose — so distant context survives.
"Backpropagation through time" means:
Unrolling the RNN turns it into a deep net with shared weights; backprop then flows through every step and the contributions to each shared weight are added up.
