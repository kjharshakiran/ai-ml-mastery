Neural Networks II: Backpropagation

The Big Question
A network has thousands — soon millions — of weights, and we can't tune them by hand. When the output is wrong, how does the network figure out which weight, deep inside, to nudge, and in which direction?

25.1 The multilayer feedforward network (MLFFNN)

Last week we built a single neuron — a weighted sum (a Week 2 dot product) followed by an activation — and stacked a few into a multilayer perceptron. Let's write that stack precisely, because the notation is the algorithm. A multilayer feedforward neural network is a chain of layers. Each layer takes the previous layer's output vector, multiplies it by a weight matrix, adds a bias vector, and squashes the result with an activation. "Feedforward" just means information flows one way: input → hidden → output, no loops.

For layer \(\ell\), with the previous layer's activation \(\mathbf{a}^{(\ell-1)}\):

\[ \mathbf{z}^{(\ell)} = W^{(\ell)}\mathbf{a}^{(\ell-1)} + \mathbf{b}^{(\ell)}, \qquad \mathbf{a}^{(\ell)} = \sigma\!\left(\mathbf{z}^{(\ell)}\right) \]

The input is \(\mathbf{a}^{(0)}=\mathbf{x}\); the final activation \(\mathbf{a}^{(L)}=\hat{\mathbf{y}}\) is the prediction. The whole network is just this one pair of equations applied again and again. Training means finding the weights \(W^{(\ell)}\) and biases \(\mathbf{b}^{(\ell)}\) that make \(\hat{\mathbf{y}}\) match the truth.

🧒 Explain Like I'm 10

Imagine a long line of friends passing a secret down the line, each one tweaking it a little before whispering it on. At the end, the last friend shouts a guess. If the guess is wrong, you walk back up the line asking each friend, "how much did your tweak mess things up?" The friends who caused the most trouble change their habits the most. Do this thousands of times and the whole line learns to pass the secret perfectly. That walk back up the line is backpropagation.

25.2 Three modes of learning

To improve the weights we need a loss — a single number measuring how wrong the prediction is — and then we slide the weights downhill on that loss (gradient descent, Week 3, in depth next week). The question is: how many training examples do we look at before each downhill step?

  • Batch (full-batch) learning. Compute the loss over the entire training set, average the gradients, then take one step. Smooth and accurate, but each step is expensive and slow — and impossible if the data won't fit in memory.
  • Stochastic (online) learning. Take a step after every single example. Steps are noisy and zig-zaggy, but cheap and frequent; the noise can even help escape bad spots.
  • Mini-batch learning. The practical middle ground used by virtually every real network: average the gradient over a small batch (commonly 32–256 examples), then step. You get most of batch's stability with most of stochastic's speed, and it maps beautifully onto GPU hardware.
🥾 Real-World Analogy

You're hiking down a foggy mountain to the lowest valley. Full-batch is surveying the whole slope around you with a laser before each careful step — accurate but exhausting. Stochastic is taking a step the instant you feel the ground tilt under one foot — fast but wobbly. Mini-batch is glancing at the ground a few paces around you, then stepping — quick, steady, and what real hikers (and real networks) actually do.

25.3 Backpropagation — the chain rule, layer by layer

This is the heart of deep learning, so we'll go slowly. Training has four beats that repeat: forward pass → loss → backward pass → update.

Forward pass. Run the equations of §25.1 left to right. Save every \(\mathbf{z}^{(\ell)}\) and \(\mathbf{a}^{(\ell)}\) — we'll need them on the way back.

Loss. Compare the prediction to the target with a loss \(L\). For a regression-style output we might use squared error \(L=\tfrac12(\hat{y}-y)^2\); for classification we use cross-entropy (§25.6).

Backward pass. We want \(\dfrac{\partial L}{\partial W^{(\ell)}}\) for every layer — how a tiny change in each weight changes the loss. Computing this directly for a deep net looks hopeless. The rescue is the chain rule from Week 3: the loss depends on \(W^{(\ell)}\) only through \(\mathbf{z}^{(\ell)}\), which feeds \(\mathbf{a}^{(\ell)}\), which feeds the next layer, and so on to \(L\). So we multiply the local derivatives along that path.

Define the error signal at layer \(\ell\) as \(\boldsymbol{\delta}^{(\ell)} = \dfrac{\partial L}{\partial \mathbf{z}^{(\ell)}}\). At the output layer it is simply how wrong we were, scaled by the output activation's slope:

\[ \boldsymbol{\delta}^{(L)} = \frac{\partial L}{\partial \mathbf{a}^{(L)}}\odot\sigma'\!\left(\mathbf{z}^{(L)}\right) \]

The magic is that the error at one layer is built from the error at the next layer — we just push it backwards through the same weights, then multiply by the local activation slope (\(\odot\) is element-wise multiply):

\[ \boldsymbol{\delta}^{(\ell)} = \left(W^{(\ell+1)\top}\boldsymbol{\delta}^{(\ell+1)}\right)\odot\sigma'\!\left(\mathbf{z}^{(\ell)}\right) \]

Once you have \(\boldsymbol{\delta}^{(\ell)}\), the gradients for that layer's weights and biases fall out instantly — the weight gradient is the error signal times the input that flowed into it:

\[ \frac{\partial L}{\partial W^{(\ell)}} = \boldsymbol{\delta}^{(\ell)}\,\mathbf{a}^{(\ell-1)\top}, \qquad \frac{\partial L}{\partial \mathbf{b}^{(\ell)}} = \boldsymbol{\delta}^{(\ell)} \]

That's the whole algorithm: compute \(\boldsymbol{\delta}^{(L)}\), then recurse the second equation back through the layers, reading off gradients as you go. It is the chain rule, organised so that no derivative is ever computed twice.

🔑 The one thing to remember

Backprop is not a new kind of math — it is the chain rule from Week 3, applied with bookkeeping. The error at a layer = (the error from the layer ahead, pushed back through its weights) × (the local slope of this layer's activation). Run that recursion from output to input and you get the gradient of every weight in one backward sweep.

Update. Now nudge every weight a small step downhill on the loss — gradient descent, with learning rate \(\eta\):

\[ W^{(\ell)} \leftarrow W^{(\ell)} - \eta\,\frac{\partial L}{\partial W^{(\ell)}}, \qquad \mathbf{b}^{(\ell)} \leftarrow \mathbf{b}^{(\ell)} - \eta\,\frac{\partial L}{\partial \mathbf{b}^{(\ell)}} \]

Repeat forward → loss → backward → update over many mini-batches and the loss falls, epoch by epoch.

25.4 Stopping criteria & configuration

One full pass over the training data is an epoch. We don't train forever — too long and the network memorises the training set (overfitting, Week 14). Common stopping criteria:

  • Validation-based early stopping — watch the loss on a held-out validation set; stop when it stops improving (or starts rising). This is the most trusted signal and we'll formalise it next week.
  • Small gradient / tiny loss change — when updates barely move anything, you're near a minimum.
  • Max epochs — a simple compute budget cap.

Key configuration knobs: the learning rate \(\eta\) (too big diverges, too small crawls — the single most important hyperparameter), the batch size, the choice of activation (ReLU in hidden layers), and how weights are initialised (small random values — never all zeros, or every neuron would learn the same thing).

25.5 Operation of an MLFFNN classifier

Putting it together, here is the life of a classifier. Training: repeatedly draw a mini-batch, forward-pass it to get class probabilities (softmax output, Week 24), measure cross-entropy loss against the true labels, backprop to get gradients, and update. Inference: once trained, you only ever run the forward pass — feed an input, read the highest-probability class. The backward pass exists purely for learning; at deployment the network is a fast, fixed function.

25.6 Logistic regression as a one-neuron classifier

Here's a lovely unification. Take the smallest possible network — a single neuron with a sigmoid activation — and you get logistic regression. The neuron outputs a probability:

\[ \hat{y} = \sigma(\mathbf{w}\cdot\mathbf{x}+b) = \frac{1}{1+e^{-(\mathbf{w}\cdot\mathbf{x}+b)}} \]

We train it with binary cross-entropy loss, which heavily punishes confident wrong answers:

\[ L = -\big[\,y\log\hat{y} + (1-y)\log(1-\hat{y})\,\big] \]

Run backprop on this one-neuron net and something beautiful happens: the gradient simplifies to

\[ \frac{\partial L}{\partial \mathbf{w}} = (\hat{y}-y)\,\mathbf{x} \]

The messy sigmoid derivative and the messy log derivative cancel exactly, leaving "prediction minus truth, times the input." This is why sigmoid pairs with cross-entropy and softmax pairs with cross-entropy — the pairing makes gradients clean and learning stable. Logistic regression, then, isn't a separate algorithm to memorise: it's a deep network with the depth dialled down to one. Stack many such neurons with non-linearities between them and you get the full MLFFNN.

25.7 A working 2-layer net for XOR, in NumPy

Time to make it real. We'll hand-write backprop for a tiny 2-layer network (one hidden layer of 4 sigmoid units, one sigmoid output) and train it on XOR — the problem from Week 24 that no single line can solve. Every line below maps directly to the equations above. Run it: the loss falls and the four XOR cases get classified correctly.

numpy — a 2-layer net trained on XOR with hand-written backprop
import numpy as np
np.random.seed(0)

# XOR data: output is 1 when exactly one input is 1
X = np.array([[0, 0], [0, 1], [1, 0], [1, 1]], dtype=float)   # 4 examples x 2 features
y = np.array([[0],    [1],    [1],    [0]],    dtype=float)   # 4 targets

def sigmoid(z): return 1.0 / (1.0 + np.exp(-z))
def dsigmoid(a): return a * (1.0 - a)        # derivative using the activation: a*(1-a)

# ---- initialise weights (small random) and biases (zero) ----
W1 = np.random.randn(2, 4) * 0.5   # input(2) -> hidden(4)
b1 = np.zeros((1, 4))
W2 = np.random.randn(4, 1) * 0.5   # hidden(4) -> output(1)
b2 = np.zeros((1, 1))

eta = 0.5                          # learning rate
for epoch in range(10000):
    # ----- FORWARD PASS -----
    z1 = X @ W1 + b1;  a1 = sigmoid(z1)      # hidden layer
    z2 = a1 @ W2 + b2; a2 = sigmoid(z2)      # output layer = prediction

    # ----- LOSS (binary cross-entropy) -----
    loss = -np.mean(y*np.log(a2 + 1e-9) + (1-y)*np.log(1-a2 + 1e-9))

    # ----- BACKWARD PASS (chain rule, layer by layer) -----
    d2 = (a2 - y)                            # output error: predicted - true  (sigmoid+BCE cancel!)
    dW2 = a1.T @ d2                          # grad for W2 = input-to-layer^T x error
    db2 = d2.sum(axis=0, keepdims=True)
    d1 = (d2 @ W2.T) * dsigmoid(a1)          # push error back through W2, x local slope
    dW1 = X.T @ d1                           # grad for W1
    db1 = d1.sum(axis=0, keepdims=True)

    # ----- UPDATE (gradient descent step) -----
    W2 -= eta * dW2; b2 -= eta * db2
    W1 -= eta * dW1; b1 -= eta * db1

    if epoch % 2500 == 0:
        print(f"epoch {epoch:5d}  loss {loss:.4f}")

# ----- final predictions -----
pred = sigmoid(sigmoid(X @ W1 + b1) @ W2 + b2)
print("predictions:", np.round(pred.ravel(), 3))   # -> ~[0.001, 1.0, 1.0, 0.0]
print("rounded    :", (pred.ravel() > 0.5).astype(int))  # -> [0 1 1 0]  XOR solved!

The loss drops from around 0.7 toward near-zero, and the final rounded predictions are [0 1 1 0] — exactly XOR. The hidden layer bent the input space (Week 24) and backprop found the weights that do the bending, all from four lines of derivative bookkeeping.

⚠️ Watch out

If you initialise all weights to the same value (e.g. zeros), every hidden neuron computes the identical thing and receives the identical gradient — they never differentiate and the net can't learn XOR. Always break symmetry with small random weights. And note the + 1e-9 inside the logs: it stops \(\log(0)\) from blowing up.

🔗 Connect the Dots

Backprop is the chain rule from Week 3 wearing a workman's apron, and the update step is the gradient descent you met in Week 3 — which Week 26 will supercharge with momentum and Adam. The neuron and activations come straight from Week 24. This single algorithm trains every deep model in the rest of the course: the CNNs of Week 28, the RNNs of Week 30, and the transformers of Week 32 all learn by exactly this forward → loss → backward → update loop. Master it once, and you've understood how every neural network on Earth learns.
